# Notes de veille – Ingénierie des données

9 février 2026. Notes de Julie Ouellet, recruteuse TI principale.

## Compétences demandées

- Langages : Python et SQL, presque toujours. Scala pour les équipes Spark.
- Orchestration et transformation : Apache Airflow, dbt.
- Entrepôts : Snowflake, BigQuery, Azure Synapse.
- Diffusion en continu : Kafka.
- Modélisation : schéma en étoile, Data Vault.

## Certifications qu'on voit le plus

- **Databricks Certified Data Engineer Associate**.
- **SnowPro Core**.
- **Microsoft Fabric Data Engineer Associate (DP-700)**.

## Ce qui distingue un bon candidat

Il parle de qualité des données avant de parler d'outils : tests sur les données, gestion des fichiers en retard, documentation des tables. Pour les clients en assurance et en finance, l'expérience des données réglementées est un atout majeur.
